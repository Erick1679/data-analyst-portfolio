# Erick Omondi — Data Analyst Portfolio

A responsive personal portfolio site for Erick Omondi showcasing four Python data analytics projects and a live Streamlit business intelligence dashboard.

## Features

- Responsive layout for desktop, tablet, and mobile
- Project descriptions and links to all four GitHub repositories
- Live Business Intelligence Dashboard link
- Technical skills: Excel, Power BI, Tableau, Stata, JASP, IBM SPSS Statistics, Python, and more
- Accessible navigation and reduced-motion support
- Plain HTML, CSS, and a minimal JavaScript date update — no dependencies or build step

## Run locally

From the project folder:

```bash
python3 -m http.server 8000
```

Open http://localhost:8000 in your browser. Press Control+C in Terminal to stop the server.

## Deploy on GitHub Pages

1. Create a **public** GitHub repository named `data-analyst-portfolio` under `Erick1679` without initializing a README.
2. Commit and push this folder to its `main` branch.
3. In the GitHub repository, open **Settings → Pages**.
4. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch to **main**, and folder to **/(root)**. Save.
5. Once GitHub publishes the site, your URL should be `https://erick1679.github.io/data-analyst-portfolio/`.

GitHub Pages documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
